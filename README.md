# Kracademy Exam Trainer

PWA para practicar las preguntas tipo test del examen de arbitraje WKF (Kata y Kumite).

- **App**: https://kracademy.github.io/exam-trainer/
- Funciona 100% offline una vez añadida a la pantalla de inicio (iOS: Compartir → Añadir a pantalla de inicio).
- Sin backend: todo el progreso se guarda en el dispositivo (con copia de seguridad exportable en Ajustes).
